# Roadmap

## v0.1: evidence-first CLI

- Secure, deterministic repository scanning
- Python AST and heuristic multi-language parser plugins
- Incremental SQLite/FTS5 index
- Stable project map and validated Mermaid architecture output
- Extractive, Ollama, OpenAI-compatible, and Anthropic answers
- Explicit cloud preview and consent
- Self-hosted FastAPI surface, cross-platform CI, Docker, and governance baseline

## v0.2: better daily use

- Tree-sitter adapters and language-specific import resolution
- Git-aware cache invalidation without collecting author identity by default
- Benchmarks across 1k, 10k, and 100k-file fixtures
- Opt-in GitHub Action that proposes project-map diffs
- PR context summaries and improved golden evaluations

## v0.3: reusable understanding layer

- Minimal read-only MCP server
- IDE integration
- Public-repository-only hosted demo with quotas and abuse controls
- Optional local embeddings and stronger graph-neighbor ranking

## Non-goals before core validation

Autonomous code changes, command execution, browser control, multi-agent orchestration, team
accounts, and claims of complete dynamic call graphs are deliberately out of scope.
